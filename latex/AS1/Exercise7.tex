\section{Exercise 7: Information Gain Ratio and Classifiers}

\begin{frame}{Information Gain Ratio and Classifiers}

In this exercise we build a decision tree classifier using the principle of maximum information gain ratio. 

A decision tree classifier is an algorithm that classifies a vector of feaures analyzing a single feature in each node and then outputting a class when it reaches a leaf node

These kind of algorithms are built using a training set of vector, whose classes are known, in a way that they classify the vectors of the training set as right as possibile, even if it's not possibile to guarantee that every vector in the training set will be classified correctly

Each categorical feaures is analysed only once in the tree, but numerical feautures can be analysed multiple times, using different threshold for comparison

\end{frame}


\begin{frame}{Selecting features}
	
When building a decision tree classifier, we must choose a feature to analyse at each node and, in the case of numerical features, also a threshold to use for comparison

Using the information gain ratio, we made the choice in order to gain the maximum amount of information about the resulting class at each step

The class and the features are treated like random variables, whose outcomes have probabilities calculated considering the occurrencies of the values in the training data set

The information gain ratio is calculated using this formula 

\[ 
IG(C|X_n) = \frac{H(C) - H(C|X_n)}{H(X_n)}
\]

The value is normalized with respect to the entropy of the feature, to failry compare features with different number of outcomes

\end{frame}



\begin{frame}{Building a decision tree}
	
To select the feature to analyze at each node, we follow this iterative process

\begin{itemize}
	
	\item If all the vector in the training set belong to the same class, that is a leaf and the value of that class is returned
	
	\item If no more feature can be analyzed and the vectors of the training set belong to different classes, return the class which is more common among the training vectors
	
	\item We calculate the normalized information gain of the class relative to each feature and, in the case of numerical features, for each possibile threshold
	
	\item We select the feature, and eventually the threshold, that have the highest information gain ratio
	
	\item We create branches for each value of the feature chosen, or for each result of the comparison of the feature with the threshold. To each branch is assigned a split of the training set made by all the vector whose values of the feature satisfy the subtree condition and we repeat the process for each subtree
	

\end{itemize}

\end{frame}

\begin{frame}{Confusion matrix}
	
	The confusion matrix of a classifier is a matrix that contains information about how good is the classifier and how many error it makes, which is why is also called error matrix
	
	Each row of the matrix represent a real value of the class of a vector, while each coloumn represent a predicted value of the class of a vector
	
	The $(i,j)$ value of the matrix is the number of vector of class $i$ that are being classified as class $j$ by the classifier. It follows that the elements on the diagonal of the confusion matrix are the number of vectors that have been classified correctly, for each possibile value of the class, while the others are the vector that have been classified incorrectly
	
	The confusion matrix of our decision tree classifier is 
	
	\[ 
		\begin{bmatrix}
		4 & 0 \\
		0 & 5 
		\end{bmatrix}
	\]
	

	
	
	
\end{frame}
